🎯 QUICK START (30 MINUTES TOTAL):

STEP 1: BACKEND DEPLOYMENT (10 minutes)
  1. Push code to GitHub: git push origin main
  2. Create Hugging Face Space (Docker SDK)
  3. Push to Hugging Face: git push huggingface main
  4. Add TMDB_API_KEY to Hugging Face secrets
  5. Wait for deployment (5-10 minutes)

STEP 2: FRONTEND DEPLOYMENT (10 minutes)
  1. Update app/frontend/.env with backend URL
  2. Push to GitHub: git push origin main
  3. Create Vercel project (import from GitHub)
  4. Set root directory to app/frontend
  5. Add VITE_API_BASE_URL environment variable
  6. Deploy (2-5 minutes)

STEP 3: TESTING (5 minutes)
  1. Test backend health endpoint
  2. Visit frontend URL
  3. Type text and submit
  4. Verify emotion detection and movies display

STEP 4: VERIFICATION (5 minutes)
  1. Check browser console for errors
  2. Test different emotions
  3. Verify CORS is working
  4. Test on mobile

🆘 COMMON ISSUES & QUICK FIXES:

Issue: 503 Service Unavailable
Fix: Wait 2-3 minutes for model to load, check Hugging Face logs

Issue: "Failed to fetch"
Fix: Verify backend URL in frontend .env, check backend is running

Issue: CORS error
Fix: Add frontend URL to CORS in main.py, rebuild backend

Issue: No movies displaying
Fix: Verify TMDB_API_KEY is valid, check backend logs

Issue: Blank page or 404
Fix: Check Vercel deployment logs, verify root directory is app/frontend
